# Glossary — Malaysia Payroll

| Term | Definition |
| --- | --- |
| EPF / KWSP | Employees Provident Fund — statutory retirement contribution scheme. |
| SOCSO / PERKESO | Social Security Organisation — Employment Injury + Invalidity Pension + SKBBK schemes. |
| EIS | Employment Insurance System (Act 800) — statutory unemployment insurance contribution. |
| HRDF / HRD Corp | Human Resources Development Fund — statutory training levy. |
| PCB / MTD | Potongan Cukai Bulanan / Monthly Tax Deduction — statutory income tax withholding. |
| SKBBK | Non-Employment Injury Security Scheme (Skim Bantuan Bencana Kemalangan/Keselamatan — additional SOCSO scheme covering non-work-related accidents). |
| HRP | Hourly Rate of Pay = Monthly Basic Wages / 26 / daily normal working hours. |
| Client Register | Payroll output from the client's existing (source/legacy) payroll system. |
| Darwinbox / Platform Register | Payroll output computed by the target SaaS payroll platform being validated. |
| Variance | Discrepancy between the Client Register and the Platform Register for a given employee + pay component. |
| Rule Engine Expected Value | The independently computed, deterministic value from PayVerify AI's statutory rule engine — the neutral third reference point in the three-way comparison. |
| Confidence Score | AI-generated likelihood that a suggestion is correct. |
